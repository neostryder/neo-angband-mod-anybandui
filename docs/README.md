# AnybandUI: quick reference

A mouse-first desktop interface for Neo Angband, ported from Wurli Monkhaven's AnybandUI. The [repository README](../README.md) describes the planned features, and [PLANNED.md](../PLANNED.md) holds the order they arrive in.

## Settings

This version has no settings. Each feature adds its own toggle to the game's Mods screen as it lands, and the toggle is listed here with its identifier and default.

## What it needs

No capabilities. The mod reads nothing from the game and draws nothing yet. Each capability joins the manifest with the feature that uses it, and this section names it then.
